## Initializing the Balancer

The `ZeroTrustBalancer` accepts an array of server configurations and an optional storage adapter.

```typescript
import { ZeroTrustBalancer, MemoryStorageAdapter } from "@emailconnector/sdk";

const balancer = new ZeroTrustBalancer({
  servers: [
    {
      id: "resend-p1",
      provider: "resend",
      apiKey: process.env.RESEND_API_KEY!,
      priority: 1,
      dailyLimit: 100,
      status: "active",
    },
    {
      id: "brevo-p2",
      provider: "brevo",
      apiKey: process.env.BREVO_API_KEY!,
      priority: 2,
      dailyLimit: 300,
      status: "active",
    },
  ],
  storage: new MemoryStorageAdapter(),
  logger: console,
});
```

## Sending an Email

### `balancer.sendEmail(params)`

```typescript
const response = await balancer.sendEmail({
  from: "Acme Notifications <notifications@acme.com>",
  to: "customer@example.com",
  subject: "Your Invoice is Ready",
  text: "Hello, your monthly invoice #INV-921 is ready to download.",
  html: "<p>Hello, your monthly invoice <strong>#INV-921</strong> is ready.</p>",
  replyTo: "support@acme.com",
  headers: {
    "X-Campaign-ID": "monthly_billing",
  },
});
```

### Return Payload: `SendResult`

```typescript
interface SendResult {
  success: boolean;
  messageId: string;
  provider: string;       // e.g. "resend" or "brevo"
  attempts: number;       // Number of servers attempted before success
  dispatchedAt: number;   // Timestamp (epoch ms)
}
```

## Dynamic Server Management

You can update server configurations at runtime without restarting your application process:

```typescript
// Add or update a server
balancer.setServers([
  ...balancer.getServers(),
  {
    id: "mailjet-p3",
    provider: "mailjet",
    apiKey: "...",
    apiSecret: "...",
    priority: 3,
    dailyLimit: 200,
    status: "active",
  },
]);

// Inspect current quota usage
const quota = await balancer.getQuotaUsage("resend-p1");
console.log(`Used today: ${quota.sentToday} / ${quota.dailyLimit}`);
```
