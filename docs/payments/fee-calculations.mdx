## Overview

Payment processing incurs gateway interchange and convenience costs. Email Connector includes a configurable fee calculation utility in `@emailconnector/config-schema`:

```typescript
import { calculateCheckoutFee } from "@emailconnector/config-schema";
```

---

## Fee Modes

### 1. Fixed Fee
Adds a flat dollar/cent amount regardless of order value:
```typescript
const fee = calculateCheckoutFee(50.00, {
  feeType: "fixed",
  fixedAmount: 1.50,
  label: "Flat Processing Surcharge",
});
// Total: $51.50 (Fee: $1.50)
```

### 2. Percentage Fee
Adds a percentage rate of the base price:
```typescript
const fee = calculateCheckoutFee(100.00, {
  feeType: "percentage",
  percentageAmount: 2.5,
  label: "Gateway Fee (2.5%)",
});
// Total: $102.50 (Fee: $2.50)
```

### 3. Combination Fee
Combines a percentage rate with a fixed surcharge:
```typescript
const fee = calculateCheckoutFee(79.00, {
  feeType: "combination",
  fixedAmount: 0.30,
  percentageAmount: 2.9,
  label: "Standard Card Processing (2.9% + $0.30)",
});
// Fee: $2.59, Total: $81.59
```
