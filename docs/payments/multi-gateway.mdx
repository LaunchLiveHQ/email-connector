## Supported Gateways

Email Connector supports 6 payment gateways out of the box:

| Gateway | Supported Currencies | Best For |
| :--- | :--- | :--- |
| **Stripe** | Global (135+ Currencies) | International cards, Apple Pay, Google Pay |
| **PayPal** | Global (25 Currencies) | Global digital wallet payments |
| **Cashfree** | INR / Global | Indian UPI, Netbanking, Cards & Instant Settlement |
| **Razorpay** | INR / Global | Indian & Southeast Asian payments |
| **DodoPayments** | USD / Global | Global digital products & SaaS merchant of record |
| **Creem.io** | Global | Creator & developer monetized subscriptions |

---

## Checkout Flow

1. Customer selects plan and preferred gateway on `/checkout`.
2. Frontend calls `POST /api/checkout/create`.
3. The server computes the fee breakdown using the Fee Engine and returns the hosted redirect URL.
4. The user completes payment on the gateway and returns to `/checkout/success`.
5. Webhook listener at `/api/webhooks/payments/[gateway]` validates the transaction and activates the license.
