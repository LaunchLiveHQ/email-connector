# Interactive Conversational Form Runner

Email Connector Forms provides an immersive, distraction-free conversational form experience (`/forms/[slug]`). Instead of overwhelming visitors with long, tedious forms, the runner presents one question at a time with smooth keyboard navigation, high-contrast inputs, and automatic progress tracking.

---

## Key Capabilities

1. **One-Question-at-a-Time Interface**: Boosts completion rates by focusing the respondent's attention on a single prompt.
2. **Keyboard Navigation**: Fast navigation using `Enter` to advance, `Shift + Enter` for multiline input, and `Escape` to reset.
3. **Conversational Field Types**:
   - Short text & long message fields
   - Email address with format validation
   - Phone numbers
   - Single-select radio pills & multi-select chips
   - Rating scales (1-5 or 1-10)
   - File uploads
4. **Real-Time Notification Delivery**: Each form submission instantly triggers transactional email alerts through your configured Email Connector providers (e.g. AWS SES or Postmark), ensuring zero missed customer inquiries.
5. **Zero-Code Embed**: Embed the form into your WordPress, Shopify, Webflow, or Next.js app with a single `<iframe>` or React component.

---

## Embedding the Form Runner

### React Component (`@emailconnector/react`)
```tsx
import { FormRunner } from "@emailconnector/react";

export function ContactPage() {
  return (
    <div className="max-w-xl mx-auto py-12">
      <FormRunner
        formId="client-onboarding-survey"
        onComplete={(submission) => {
          console.log("Form submitted successfully:", submission.id);
        }}
      />
    </div>
  );
}
```

### Direct Hosted Link or Iframe
Every published form receives a clean, shareable URL:
```html
<iframe
  src="https://email-connector.com/forms/contact-us"
  width="100%"
  height="600"
  frameborder="0"
  allow="camera; microphone; autoplay"
></iframe>
```

## Form Submissions & Webhook Integrations

When a user completes a form:
- The response is securely stored in your Convex database.
- A cryptographically signed HMAC webhook (`X-EmailConnector-Signature`) is dispatched to your CRM, Make, or Zapier endpoint.
- An instant email notification is delivered to your designated team inbox via your primary email provider.
