## Overview

The Go Gateway includes a native **Model Context Protocol (MCP)** server complying with JSON-RPC 2.0 over `stdio`. It empowers autonomous AI agents to send emails, generate test mailboxes, and poll incoming messages (with automatic OTP extraction).

---

## Configuring AI Clients

### 1. Claude Desktop
Add to your `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "email-connector": {
      "command": "/path/to/email-connector/apps/gateway-go/mcp"
    }
  }
}
```

### 2. Cursor
Go to **Cursor Settings > Features > MCP**, click **Add New MCP Server**:
- **Name:** `email-connector`
- **Type:** `command`
- **Command:** `/path/to/email-connector/apps/gateway-go/mcp`

## Exposed MCP Tools

### `send_email`
Dispatches an email across the zero-trust cluster.
```json
{
  "name": "send_email",
  "arguments": {
    "from": "agent@yourdomain.com",
    "to": "user@example.com",
    "subject": "AI Report Ready",
    "text": "Your automated report has been generated."
  }
}
```

### `create_inbox_alias`
Creates a dedicated mailbox on `in.email-connector.com` for testing.
```json
{
  "name": "create_inbox_alias",
  "arguments": {
    "alias": "qa-signup-test"
  }
}
```

### `poll_inbox_messages`
Retrieves received messages, with stripped reply chains and extracted OTPs.
```json
{
  "name": "poll_inbox_messages",
  "arguments": {
    "address": "qa-signup-test@in.email-connector.com",
    "limit": 5
  }
}
```

### `list_inboxes`
Lists all active test inboxes.
