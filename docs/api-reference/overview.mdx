## Base URLs

- **Production Control Plane:** `https://email-connector.com`
- **Go Gateway (Local/Self-hosted):** `http://localhost:8080`

---

## Endpoints Summary

| Method | Path | Description |
| :--- | :--- | :--- |
| `POST` | `/api/checkout/create` | Create a checkout session with dynamic fee calculation. |
| `POST` | `/api/v1/subscriptions/verify` | Validate subscription license key and return unlocked drivers. |
| `POST` | `/api/forms/submit` | Ingest interactive conversational form submissions. |
| `GET` | `/api/r/[slug]` | 307 affiliate redirect with click telemetry tracking. |
| `POST` | `/api/v1/inbound/webhook` | Ingest raw RFC 5322 MIME email on the Go Gateway. |
| `POST` | `/api/v1/dispatch` | Queue an outbound webhook job on the Go Gateway. |
