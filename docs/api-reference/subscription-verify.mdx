---
title: "Verify Subscription"
api: "POST /api/v1/subscriptions/verify"
description: "Verify a client license key and return unlocked enterprise drivers."
---

### Request Body

<ParamField body="subscriptionId" type="string" required>
  The customer's subscription license key (e.g. `ec_sub_pro_demo` or `ec_test_enterprise`).
</ParamField>

---
