---
title: "Inbound Email Webhook"
api: "POST /api/v1/inbound/webhook"
description: "Ingest raw RFC 5322 MIME or JSON email payloads on the Go Gateway."
---

### Headers

- `Content-Type`: `message/rfc822` (for raw MIME) or `application/json`

---

### Request Body (Raw MIME)

Send raw email stream (RFC 5322 / RFC 2045):

```http
From: security@service.com
To: user@in.email-connector.com
Subject: Your Verification Code
Content-Type: text/plain; charset="utf-8"

Your verification code is 849201.
```

---

### Response Example

```json
{
  "success": true,
  "messageId": "<9018239@service.com>",
  "from": "security@service.com",
  "to": ["user@in.email-connector.com"],
  "subject": "Your Verification Code",
  "cleanBody": "Your verification code is 849201.",
  "extractedOtp": "849201",
  "actionLinks": []
}
```
