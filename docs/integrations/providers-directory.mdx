# Supported Providers Directory

Email Connector supports over 40 leading email service providers, newsletter publishing engines, and transactional APIs. You can connect, combine, and failover between any of these providers using one consistent integration interface.

## Adding a Custom Provider

Need to connect an internal SMTP relay or proprietary provider? Email Connector supports custom HTTP drivers and SMTP credentials:

```typescript
import { ZeroTrustBalancer } from "@emailconnector/sdk";

const balancer = new ZeroTrustBalancer({
  providers: [
    {
      id: "custom-smtp",
      type: "smtp",
      host: "smtp.internal.company.com",
      port: 587,
      user: process.env.SMTP_USER!,
      pass: process.env.SMTP_PASS!,
      lane: "transactional"
    }
  ]
});
```
