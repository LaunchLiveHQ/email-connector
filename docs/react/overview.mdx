## Installation

```bash
npm install @emailconnector/react @emailconnector/config-schema
```

### Peer Dependencies
`@emailconnector/react` requires React 18 or 19 and Tailwind CSS:
- `react`: `>=18.0.0`
- `react-dom`: `>=18.0.0`
- `lucide-react`: `^0.475.0`

---

## Setting up the Provider

Wrap your application or settings page with `<EmailConnectionProvider />`:

```tsx
"use client";

import { EmailConnectionProvider } from "@emailconnector/react";

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <EmailConnectionProvider>
      {children}
    </EmailConnectionProvider>
  );
}
```

## Component Suite

| Component | Description |
| :--- | :--- |
| **`<SendingServersTable />`** | Priority management table with status toggles, quota gauges, and action dropdowns. |
| **`<AddServerModal />`** | Server configuration modal with dynamic provider credentials and pre-flight handshake button. |
| **`<QuotaGaugeCard />`** | Real-time circular SVG progress gauge displaying active daily pool consumption. |
| **`<SubscriptionUnlockModal />`** | Modal to enter subscription license keys and unlock 20+ enterprise ESP drivers. |
| **`<FormRenderer />`** | Conversational multi-step interactive form runner with keyboard navigation. |
