---

## Usage

```tsx
import { QuotaGaugeCard } from "@emailconnector/react";

export function DashboardOverview() {
  return (
    <div className="grid grid-cols-1 md:grid-cols-3 gap-6">
      <QuotaGaugeCard />
    </div>
  );
}
```

---

## Behavior

- Automatically aggregates the total daily limits across all active servers (e.g. `800 emails/day`).
- Shows total dispatched today and percentage consumed.
- Dynamic color threshold: Green (`< 70%`), Amber (`70% - 90%`), Red (`> 90%`).
