## Why Direct Sending Matters (No Middleman)

In traditional email management, developers and businesses often connect their domains to centralized third-party routing platforms. This introduces privacy and security risks:

1. **Third-Party Key Storage:** Your provider API keys are stored in an external company's database.
2. **Messages Read by Intermediaries:** Password resets, receipts, and private customer messages pass through intermediate servers.
3. **Privacy Compliance:** Centralized proxies become extra data processors that need additional compliance agreements.

---

## How Direct & Private Sending Works

Email Connector connects directly from your application to your email provider:

```
  ┌────────────────────────────────────────────────────────┐
  │              YOUR SERVER / EDGE RUNTIME                │
  │                                                        │
  │  1. ZeroTrustBalancer loads local API keys             │
  │  2. Evaluates daily quota & server priority            │
  │  3. Formats payload & executes Direct HTTPS request   │
  └──────────────────────────┬─────────────────────────────┘
                             │
                             │ Direct TLS 1.3 Request
                             ▼
  ┌────────────────────────────────────────────────────────┐
  │                 RECIPIENT ESP CLOUD                    │
  │         (Resend, Brevo, Mailjet, AWS SES)              │
  └────────────────────────────────────────────────────────┘
```

<Note>
**Guaranteed Isolation:** At no point during the execution of `balancer.sendEmail()` is any network packet sent to `email-connector.com` or any centralized cloud endpoint.
</Note>

## Managing Server Configurations Securely

When using `@emailconnector/react` to allow users or administrators to input sending credentials:
- Credentials can be encrypted locally using your application's KMS key before saving to your own database.
- The pre-flight test handshake executes directly from your server to test SMTP or REST credentials before committing them.
